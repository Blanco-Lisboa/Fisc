# WhatsApp do Fiscal — atalhos (iguais ao WhatsApp Web/Desktop)

Valem no módulo WhatsApp e na conversa da Apuração (mesmo código).

| Atalho | O que faz |
|---|---|
| Enter | envia (caixa normal e caixa de cada arquivo) |
| Shift+Enter | pula linha (em todas as caixas) |
| Ctrl+B / Ctrl+I / Ctrl+Shift+X | negrito / itálico / riscado no texto selecionado (*, _, ~) |
| Ctrl+V | cola arquivos e imagens na conversa |
| / (caixa vazia) | abre os modelos |
| Esc | fecha menu, janela, resposta, busca ou a conversa |
| Ctrl+Alt+Shift+U ou Ctrl+Shift+U | marcar como lida / não lida |
| Ctrl+Alt+Shift+M ou Ctrl+Shift+M | silenciar / reativar |
| Ctrl+Alt+Shift+E ou Ctrl+Shift+E | arquivar / desarquivar |
| Ctrl+Alt+Shift+P ou Ctrl+Shift+P | fixar / desafixar |
| Ctrl+Alt+/ ou Ctrl+F | buscar na lista de conversas |
| Ctrl+Alt+Shift+F ou Ctrl+Shift+F | buscar na conversa |
| Ctrl+Alt+Tab ou Ctrl+Tab | próxima conversa (Shift junto = anterior) |
| Ctrl+Alt+Shift+N ou Ctrl+Shift+N | novo grupo (gestor) |
| Ctrl+Alt+P ou Ctrl+P | dados do contato |
| Ctrl+Alt+E ou Ctrl+E | painel de emojis |

Sem equivalente na API oficial (não existem no nosso): apagar conversa, nova conversa livre (só por modelo), GIF e figurinha.

Fontes: https://www.xda-developers.com/whatsapp-keyboard-shortcuts/ · https://hongkiat.com/blog/keyboard-shortcuts-whatsapp

Apuração: a conversa do cliente vem da tabela wa_mensagem, achada pelo CNPJ (empresa vinculada ao contato). A lista de
clientes da Apuração ainda é de exemplo até a decisão da fonte dos dados; por isso só aparece conversa quando o CNPJ do
exemplo bate com uma empresa vinculada a um contato.
